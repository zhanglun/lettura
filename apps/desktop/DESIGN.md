# Design — Lettura 0.2.0「静密 × 聚光」

> 从已构建的参考实现记录（ground truth over intention）。
> 参考实现：`.impeccable/mocks/decision/fusion.html`（可交互：j/k · Enter · esc · m · f · space · ⌘K）

## 世界一句话

界面是一台睡在玻璃上的精密仪器——排版做层级，键盘做导航，命令面板做入口；内容即界面，读完就走。

## 色板（Restrained：中性 + 单强调）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ground` | `#F4F4F1` | 画布 |
| `--glass` | `rgba(255,255,255,.78)` + `backdrop-filter: blur(22px) saturate(1.5)` | 主面板 / 播放卡 / 命令面板 |
| 环境光 | 红 `rgba(232,80,96,.05)` 左上 + 靛 `rgba(94,109,210,.055)` 右上（radial） | 画布氛围，极淡 |
| `--ink` / `--sub` / `--ter` | `#1D1E20` / `#6A6C6E` / `#9EA0A2` | 文字三级 |
| `--hair` / `--hair2` | `rgba(29,30,32,.08)` / `.13` | 发丝线 / 边框 |
| `--accent` | `#5E6AD2`（靛蓝） | 唯一强调色：焦点线、圆点、播放、选中 |
| `--accent-soft` | `rgba(94,109,210,.1)` | 选中底、圆点光环 |
| `--pink` | `#E86A92` | 仅 B站徽章 |
| `--warn` | `#C4564A` | 同步失败 |
| `--amber` | `#E5A50A` | 仅星标 |

## 字体

- UI：`-apple-system, "SF Pro Text", "PingFang SC"`，中文 `letter-spacing: .005–.01em`
- 文章正文：`"Songti SC", "STSong", "Noto Serif SC"`，15.5px / 行高 2.0（外壳精密，内容读书）
- 数字一律 `font-variant-numeric: tabular-nums`；时间码用 `SF Mono`
- 字阶：26（页题）/ 24（详情题）/ 21 / 14.5 / 13.5（行题）/ 13 / 12.5 / 12 / 11.5 / 11 / 10.5（kbd、足注）

## 布局骨架

```
画布（ground + 双色 ambient）
└─ 玻璃主面板  inset:22px 22px 106px · radius 16 · 内高光 1px
   ├─ 顶栏 54px：logo 点 + 章节 + 计数药丸 + 导航(未读/星标/历史/订阅) + ⌘K 搜索钮
   ├─ 过滤条 42px：全部/文章/播客/平台（计数） + 右侧同步元信息
   └─ 视图区（列表 ⇄ 详情 ⇄ 设置，面板内替换，位置保留）
└─ 全局浮动玻璃播放卡  inset:22px bottom:22px · h68 · radius 14（有音频时才在）
└─ ⌘K 命令面板  580px · top 84 · 浮层 + 压暗 veil
```

## 组件与状态

**列表行**（54px，发丝线分隔，grid：状态点/徽章/题/源/时间/动作）：

| 状态 | 记号 |
|---|---|
| 未读 | 6px 靛蓝圆点 |
| 已读 | 圆点转灰，题转灰 400 |
| 键盘焦点 | 浅底 + **2px 靛蓝左线** + 圆点 3px 光环（硬状态，禁 hover 洗色） |
| 播放中 | 源列「播放中」靛蓝字 |
| 星标 | 行尾琥珀星 |
| 同步失败 | 源列 `#C4564A` + 重试 |

**类型徽章**（20px，radius 6，10px 粗字）：文＝中性灰 · 播＝靛 · B＝粉 · 抖＝深灰。

**详情视图**（类型感知，同一外壳）：

| 类型 | 内容 |
|---|---|
| 文章 | ≤640px 单栏，宋体正文 |
| 播客单集 | 112px 封面 + 大播放控件 + 章节（时间码）+ show notes |
| 平台（B站/抖音） | 封面块 + feed 简介 + 黑色「在平台打开」外跳钮（0.2.0 不做站内视频） |

**命令面板**：输入即时过滤（文章 / 来源 / 命令混合），首项选中（`--accent-soft` 底 + 1px 内线），kbd 提示，底部快捷键栏；「打开设置」命令进设置视图。

**播放卡**：播放/暂停、±30s、单集信息（点击展开单集详情）、进度条带旋钮、倍速 chip、展开箭头。

**设置视图**（面板内第三态，参考实现 `.impeccable/mocks/decision/settings.html`）：

顶栏章节变「设置」（订阅管理时「设置 · 订阅」），队列计数药丸持续在场；视图头部与详情同构（返回钮 + esc）。入口：⌘K「打开设置」；导航点「未读」或 esc 一路退回（设置 → 未读 / 订阅 → 设置），列表位置保留。

| 语法 | 规则 |
|---|---|
| 版心 | 居中 680px，段题用章节字（11px/700/.1em/`--ter`） |
| 设置行 | 标签左（13.5px/500 + 帮助文字 11.5px/`--sub`）、控件右、发丝线分隔，min-h 52，hover `.02` |
| 控件词汇 | 分段＝过滤条 tab 语法（胶囊容器）；下拉＝⌘K 钮语法 + 菜单浮层（`.94` 白 + 模糊）；开关＝36×21、on＝`--accent`；滑杆＝进度条语法（3px 轨 + 白环旋钮）+ 数值 chip；主钮＝墨底、幽灵钮＝发丝边 |
| 校准台 | 外观段尾预览块：列表行样本 + 宋体段落，实时反映字号/行高/密度/强调色；拖动即显影，无过渡 |
| 订阅行 | 列表行收紧至 44px：类型徽章/题/未读药丸/域名/时间/悬停动作；分组头部 32px 可折叠，动作用悬停显隐；右键菜单＝命令面板浮层语法，退订为 `--warn` |

状态反馈即时生效（无保存钮），写入本地配置；同步失败在健康行与订阅行以 `--warn` 呈现并附重试。

## 键盘模型

```
j / k / ↑↓   移动焦点（详情内 = 下一篇/上一篇）
Enter / o    打开焦点行
Esc          返回列表 / 关闭面板（设置内逐级返回：订阅→设置→列表，位置保留）
m            已读并下移        M   已读并上移
f            星标              v   浏览器打开原文
space        全局播放/暂停     R   刷新全部来源
⌘K 或 /      命令面板（含「打开设置」）    ?   快捷键帮助
```

## 动效

- 行 hover：`rgba(29,30,32,.035)`，无位移
- 圆钮 hover：`scale(1.05–1.06)`，150ms ease
- 播放卡/软卡类：translateY(-1px) + 阴影抬升，150–160ms ease
- 禁止：入场动画全家桶、渐变文字、零模糊色块阴影、彩色粗边框

## 范围约束（0.2.0）

- 视频平台内容：徽章 + feed 简介 + 外跳，**不做站内播放**
- 深色模式为命名候（「夜读本」），不是简单反色；颜色永不作唯一信号
- AI 不进界面；无 API Key 零损失
