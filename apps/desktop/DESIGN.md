## 世界一句话

界面是一台睡在玻璃上的精密仪器——排版做层级，键盘做导航，命令面板做入口；内容即界面，读完就走。

| **未读列表 = 时间流 + 源棱镜（2026-09-29 用户拍板，推翻 09-26 按源分段）** | 未读回到**纯发布时间倒序单流**（`pub_date` 缺省退 `create_date`；同 feed 连片是发布时刻相邻的涌现现象，不是排序结构）。**退役**：同源段头（fusion-runhead）、长段折叠（feedRuns）、队列索引条（fusion-runindex）整套机制——它们是「按源塞进时间流」逼出来的复杂机器。**导航锚点**：吸顶日期分隔条（六桶定稿：今天/昨天/本周=前天~6天前/上周=7~13天前/30天内=14~29天前/更早，`.fusion-dayhead`），**全部桶整行可点收起/展开**（收起是显式点击可随时展开，决定权交用户；默认态 2026-09-30 用户拍板改为：**只默认展开第一个非空时间组**（今天没数据则依序落到昨天/本周…），其余含「更早」全部收起——**换过滤口径（载体 tab/源棱镜/队列帧）即重新应用默认展开**（2026-09-30 用户拍板：切到视频/播客同样默认展开第一个非空组，不继承上一口径的展开态；回到访问过的口径走 SWR 缓存同步命中立即应用）；同口径内的计数刷新（单篇已读、防抖 refresh）不重排用户手动展开/收起，封印按口径记；`useArticle` 的 scoped 摘要未返回时 `dayCounts` 为 undefined（不退回全局口径——退回会先按全局分布展开再跳一次，日期头也会短暂挂错口径数字）；会话级不持久化——日期桶随时间漂移，持久化语义混乱）；**每桶独立懒加载**（2026-09-29 三次演进：扁平分页 → 按源分段 → 每桶一条 SWRInfinite 通道）——展开空桶自动首拉该桶、桶内滚动 loop 续载本桶、拉完即停，不再需要翻完今天的 760 篇才能看到昨天；`ArticleFilter.day_bucket` 服务端桶过滤（纯 A 列条件，全局免 JOIN 不受影响）。**桶计数 = 服务端同条件真实分布**且**分双口径**：顶栏载体 tab 计数 = 全局 summary（不随激活 tab 变，tab 计数本身就是全局分布）；日期头计数 = 含当前载体条件的作用域 summary（第二缓存键，切 tab 重新统计）——计数已知为 0 的桶整个不渲染（用户实测：切播客后日期头还挂全局数字、空桶照样渲染）。收起桶里的行从 j/k 可达序列剔除，与渲染严格一致。**按源 = 按需透镜**：过滤条右端一枚源棱镜（`FeedPrism`，`.fusion-prism*`）——默认露出最近同步的 3 个源图标作引力点，**点击弹出轻量源清单**（Astryx `Popover`，搜索+分组+徽标，264px；2026-09-30 用户拍板从 HoverCard 悬停改为点击——悬停误触频繁，点击才是明确意图；浮层容器视觉退让 Astryx），**选源 = 未读流原地过滤**（查询加 feed_uuid，不切队列帧、不跳源详情路由；选中后 pill 显示源名，清单「全部」行清除，2026-09-30 改版——此前点选跳源详情，用户反馈切断未读流）；不常驻一寸导航（曾评估 Feedly 式常驻源面板，否决：本质是邮件客户端形态，违背「界面消失」）。**焦点语义**：队列身份（源/过滤组合键）变化即清零焦点并**滚动归零**（2026-09-30 补滚动：换了一个队列，滚动条回顶部；分页加载与 esc 从详情回列表不触发，位置保留）——ArticleView 被路由跨路由复用，focusIdx 会活过视图切换，残留高亮像「默认聚焦」（用户实测）；首次 j 落首行 = 建立光标不亮样式（`focusStyleSuppressed`），第二次 j 起正常；esc 从详情回列表焦点跟随阅读位置（同一队列，设计内）。三方案对比稿在 mocks：list-timeline（A）/list-rail（B）/list-prism（C，拍板）。⏎/m/f/v 等键盘模型不变。相对时间中文化：date-fns `formatDistanceToNow` 默认英文，共享 `formatRelative`（feedMeta）按界面语言传 `zhCN` locale，四个调用点（列表行/阅读页头部/下一篇卡/源行同步时间）统一走它——locale 键与 `BUCKET_ORDER` 同属「改桶集合要同步的两处清单」 |
| **列表路径性能（2026-09-29，随 C 方案落地）** | 真库（36k 篇）实测的三个压屏聚合是「卡」的真凶，与分段无关：①同条件 COUNT 带 feeds JOIN 687ms→全局过滤免 JOIN 37ms（`article_filter_parts.uses_join` 判定）；②COUNT 与载体计数两趟带 JOIN 全表聚合（687+3187ms）合并为 `get_article_summary` 单趟扫描（~30ms），前端 `useArticle` 一次取回；summary 同趟带日期桶分布（day_today/yesterday/thisweek，earlier=total−三桶）供分隔条真实计数；③订阅树未读数物化——`feeds.unread_count` 列（迁移 2026-09-29-000000，初值回填+部分索引），写路径增量维护（`add_articles` +N、单条已读 ±1、组头全部已读/全部已读 `recalc` 校准），`get_unread_total` 读列+分组向上累加，217ms→0。keyset 分页（OFFSET 消除）列为后续项 |
| 同源连跑段头（2026-09-26） | 跨源队列（全部/星标/历史）里**连续 ≥3 篇同一 feed** 时插入段头（`.fusion-runhead`）：源图标 + 源名 + 「N 篇」+ 规则线 + 悬停全显「全部已读」；1-2 篇不立头（行内已有源名）；源队列帧不立头 |
| **按源分组替代全局时间倒序（2026-09-26 用户决策）** | 跨源队列排序从「纯时间倒序」改为「**按 feed 分组**」：同一 feed 只出现一段（消除被其他源隔断的碎片），**组间按该源最新文章时间倒序**（首篇即最新篇，保留「谁刚更新看谁」的时序感），组内时间倒序。操作单元是 feed（展开/全部已读/索引跳转皆按源），时间倒序按 feed 内部保留 |
| 长段折叠 + 队列索引条（2026-09-26） | 解决「单一 feed 刷屏占满视口」：**连续 ≥8 篇**默认折叠为段头 + 前 3 篇预览 + 「还有 N 篇」尾行（会话级记忆展开态，模块级 `feedRuns`）；列表顶部**吸顶索引条**（`.fusion-runindex`，玻璃底 + 发丝线）以 chips 一览队列中所有段：源图标 + 源名 + 未读数（有未读＝accent），点击＝展开该段并平滑跳转 + 段头 accent 闪光（`scroll-margin-top 46px` 让位吸顶条）；j/k/⏎/m/下一篇全部沿折叠后**可见序列**走（`flattenDisplay`），隐藏行不可达；全部已读仍按整组（含隐藏篇）计 |
| 段头交互（2026-09-26） | **可折叠段的整行点击 = 展开/收起**（行同款 4% 墨洗 + chevron 转向），不跳源队列——进源队列走订阅浏览帧；不可折叠的段头（3-7 篇）是静态标签；「全部已读」钮 stopPropagation 独立响应 |
| 段头全部已读 = feed 级（2026-09-26） | 组头「全部已读」清的是**该源的整个未读队列**（服务端 `mark_as_read` 单条 SQL，含未加载的历史未读）——只标已加载行对几百条历史未读的源没有意义。本地 retain 已加载行 + `updateCollectionMeta(0, -feed.unread)` + toast 报实际数量 + `getSubscribes` 刷新徽标；按钮在有未读（行内或订阅表）时显示。**并发写教训**：逐条并发落库会撞 SQLite 锁（连接无 busy_timeout 时仅前几条生效，handler 把 Err 吞成 0 静默失败）——批量写一律走单条 SQL；`establish_connection` 补 WAL + busy_timeout=5000（与测试分支对齐），Rust 侧需重启生效 |
| 数字对账（2026-09-26；足注节流 2026-09-30） | strip 计数=服务端同条件**全量**口径（`/api/articles/carrier-counts`，与列表接口共用 `article_filter_conditions`，已实测同数）；列表=懒加载（20/页）+ 按源折叠摘要，可见行数天然少于计数。桥接：①列表尾部足注「已加载 N / 共 M 篇」（`.fusion-list-foot`）——**只在加载中 / 有更多可载 / 队列末尾出现**，满载的中间桶不再重复「已全部显示」（组头已有同一句计数，逐桶重复是分组节奏噪音，2026-09-30）；②索引条 chips 数=该源条数；③单篇标记已读/切换读状态后计数**防抖刷新**（600ms），strip 数字始终是当前队列；④**无限加载对折叠免疫**（2026-09-26 修复）：触底判定除滚动事件外，布局变化（首屏/展开收起/新页）后主动补判——「列表不足一屏」时没有滚动事件，不补判链条就死在第一页；自动补载仅在「无滚动条或触底」时触发，20 页预算封顶（病态零增长队列防打满），过滤切换（query 变化）时分页深度与门闩/预算一并归位 |
| 静默空态（2026-09-28） | 小幅空态（⌘K 无结果 / 列表过滤空 / 源队列无未读 / 星标空 / 订阅搜索空）＝共享 `QuietEmpty`（`.fusion-empty`）：发丝线圆角印章 glyph（lucide 1.25 线重，唯一一次落定动效，reduced-motion 关闭）+ 13.5px 标题 + 12px 提示 + **按语境的恢复动作**（载体过滤空→切回全部；源队列无未读→查看全部文章；订阅搜索空→清除搜索并隐去零匹配分组头；零订阅→添加订阅）。文案按成因分型，不再共用一句「哎呀」；与 empty.html 的全视图空面（EmptyFace）同一语言，不画插画。⌘K 面板用 compact 档 |
| `--color-accent` | **Astryx 主题 accent，直接消费、无任何 fusion 间接层**（2026-10 契约）：主题即调色板身份，五色板已删；gothic 为永久深色主题，选中即强制深色 | 唯一强调色：焦点线、圆点、播放、选中、正文链接 |
| `--color-accent-muted` | Astryx 自带 accent 淡底令牌（各主题自带设计值） | 选中底、淡色洗 |

## 字体

- UI：`-apple-system, "SF Pro Text", "PingFang SC"`，中文 `letter-spacing: .005–.01em`
- 文章正文：与外壳同族 sans，固定 15.5px / 行高 1.85（2026-10-05 用户拍板移除宋体与字号/行高定制——定制系统未让阅读更好；`--read-size`/`--read-lh`/`--fusion-serif-ink` 令牌已删）
- 数字一律 `font-variant-numeric: tabular-nums`；时间码用 `SF Mono`
- 字阶：26（页题）/ 24（详情题）/ 21 / 15.5（正文）/ 14.5 / 13.5（行题）/ 13 / 12.5 / 12 / 11.5 / 11 / 10.5（kbd、足注）

## 布局骨架

```
画布（ground + 双色 ambient）
└─ 玻璃主面板  inset:22px · radius 16 · 内高光 1px（铺到窗口下缘）
   ├─ 顶栏 54px：logo 点 + 产品名「Lettura」+ 计数药丸（全局未读常驻；订阅浏览帧显示源数） + 导航(未读/星标/历史/订阅) + ⌘K 搜索钮——当前位置由导航高亮表达，顶栏不放视图名
   ├─ 过滤条 42px：全部/文章/播客/视频（+邮件，仅在真有邮件内容时出现）——**按载体分档**；全部与各档计数均为**服务端同条件真实总数**（`/api/articles/carrier-counts`，不随分页截断） + 右侧同步元信息 + 同步/全部已读图标钮
```

- 描述读纯文本（不渲染远程 HTML）；复制/外跳复用 `copyText` + `plugin-shell`

浏览帧源行列宽微调：`22px 1fr minmax(150px,210px) 56px 108px`（行内距 10px，内容不贴洗色边缘）——host 列并入「经 Route」来源提示，时间列加宽并加 ellipsis（英文「about 17 hours ago」不再与未读数黏连）；域名列不给原生 tooltip（悬停弹系统灰块压在行清单上是噪音，截断即省略号，2026-09-30）；源 logo 加载失败退回首字占位（同文章行字符契约）。

键盘：浏览帧 j/k 跳过零未读源、⏎ 进队列、esc 回未读列表；队列帧即列表语法（⏎ 进阅读面、m/f 同全局）。星标/历史导航项＝列表变体（已读行/星标行），由列表语法覆盖，无独立稿。

## 键盘模型

```
j / k        列表：移动焦点 · 详情：滚动文章（到边即停）
↑ / ↓        焦点移动（详情内 = 上一篇/下一篇；订阅浏览帧同 j/k）
Enter / o    打开焦点行
Esc          返回列表 / 关闭面板（设置：esc 直达进入前页面，位置保留）
m            已读并下移        M   已读并上移
f            星标              v   浏览器打开原文
space        全局播放/暂停     ← →   播客 ±30s
R            刷新全部来源      c   添加订阅
⌘K 或 /      命令面板（含「打开设置」）    ?   快捷键帮助
```

键位定义单一事实源：`src/shortcuts.ts`（HK 绑定串 + SHORTCUT_GROUPS 展示行），帮助浮层与各视图 `useHotkeys` 都从这里引用——新增/改键只改一处。

## 动效

- 行 hover：`rgba(29,30,32,.035)`，无位移
- 圆钮 hover：`scale(1.05–1.06)`，150ms ease
- 播放卡/软卡类：translateY(-1px) + 阴影抬升，150–160ms ease
- 禁止：入场动画全家桶、渐变文字、零模糊色块阴影、彩色粗边框、**彩色竖侧线**（`border-left/right` >1px 或 inset 侧影做状态记号——状态用洗色 + 字重 + 圆点光环表达）

## 范围约束（0.2.0）

- 视频平台内容：徽章 + feed 简介 + 外跳，**不做站内播放**
- 深色「夜读本」已定稿（`.impeccable/mocks/decision/dark.html`，见下方令牌表）；颜色永不作唯一信号；切换机制：`userConfig.color_scheme` 单源派生 `body.dark-theme` 与 Astryx `data-theme`（App 内单一 effect 同步，设置页只写 store）
- AI 不进界面；无 API Key 零损失

## 夜读本令牌（深色，非反色）

同一台仪器在夜间的样子：暖黑画布（非蓝黑）、更深更透的玻璃、上缘冷内高光、昼间双色环境光弱化为月相残照。全部面（列表/详情/设置/订阅/添加/帮助/空状态）继承此令牌层，结构与组件语法不变。

| 令牌 | 夜读值 | 昼读值 |
|---|---|---|
| `--ground` | `#17171A`（暖黑） | `#F4F4F1` |
| `--glass` | `rgba(22,22,25,.72)` + blur 22 saturate 1.3 | `rgba(255,255,255,.78)` + saturate 1.5 |
| 内高光 | 上缘 `rgba(233,233,230,.09)`（冷） | 上缘白 `.7`（暖） |
| `--ink` / `--sub` / `--ter` | `#E9E9E6` / `#A2A4A8` / `#6B6D73` | `#1D1E20` / `#6A6C6E` / `#9EA0A2` |
| `--hair` / `--hair2` | `rgba(233,233,230,.08/.13)` | `rgba(29,30,32,.08/.13)` |
| `--accent` | `#848CE8`（提亮保对比） | `#5E6AD2` |
| `--paper` | `#26262B`（阅读面抬高的暗纸，仅详情正文区） | ——（昼读正文直落在玻璃上） |
| `--warn` / `--amber` / `--pink` | `#D97B6F` / `#EDB433` / `#EE8BAB`（均提亮） | `#C4564A` / `#E5A50A` / `#E86A92` |
| veil 压暗 | `rgba(0,0,0,.32)` | `rgba(29,30,32,.14)` |
| 阴影系 | 全部转黑基（`rgba(0,0,0,…)`） | 黑基不变 |
| 环境光 | 双色残照（约昼间 60% 弱） | 双色极淡 radial |

实测对比度（暗玻璃上）：ink 14.8 / sub 7.2 / accent 5.9 / warn 6.0——全面优于昼读值。徽章与药丸的灰阶改用浅色投影（`rgba(233,233,230,…)`)。`--serif-ink`（宋体暗墨）随宋体正文一起移除（2026-10-05）。
